# مختبر الأزياء

تطبيق ويب يشغّل نموذج CNN مدرَّباً على Fashion-MNIST **داخل المتصفح** بدون سيرفر.
دقة النموذج على بيانات الاختبار: **91.54%** (220,874 معامل).

## الصفحات
| الصفحة | الفكرة |
|---|---|
| `index.html` | الرئيسية وعرض حي للنموذج |
| `donate.html` | فرز التبرعات: تصنيف دفعة صور وعدّ كل فئة وتصدير CSV |
| `wardrobe.html` | خزانتي: حفظ القطع في المتصفح، ما ينقص الخزانة، واقتراح إطلالة |
| `challenge.html` | تحدَّ النموذج: رسم حر ولعبة خمس جولات |
| `lab.html` | مختبر النموذج: منحنيات التدريب، البنية، مصفوفة الالتباس، العينات |

## مسار العمل
1. تدريب CNN على Fashion-MNIST في Colab وحفظه `.keras`
2. تصدير الأوزان إلى JSON بـ `tools/export_model.py` ← `data/model.json` و `data/lab.json`
3. `js/engine.js` يعيد حساب الطبقات (Conv، BatchNorm، MaxPool، Dense، Softmax) بجافاسكربت خالص
4. تجهيز الصورة (`Prep` في نفس الملف): إزالة الخلفية، قص القطعة، تصغيرها إلى 28×28
5. واجهات HTML/CSS/JS ثابتة بتصميم زجاجي
6. النشر على GitHub Pages

## التحقق
- محرك المتصفح يطابق تنبؤات Keras على 200 من 200 صورة اختبار (يظهر الفحص في `lab.html`).
- النموذج دُرّب على صور رمادية 28×28 لقطعة واحدة على خلفية سوداء، فتقلّ دقته على صور الجوال المزدحمة.

## النشر على GitHub Pages (بالنقر فقط)
1. أنشئ حساباً مجانياً على github.com.
2. اضغط **+** أعلى الصفحة ثم **New repository**. اكتب اسماً مثل `fashion-lab`، واختر **Public**، ثم **Create repository**.
3. في صفحة المستودع اضغط **uploading an existing file**.
4. افتح مجلد المشروع على جهازك، حدّد **كل محتوياته** (index.html و css و js و data و tools ...) واسحبها إلى الصفحة. لا ترفع المجلد الأب نفسه.
5. انتظر انتهاء الرفع ثم اضغط **Commit changes**.
6. من **Settings ← Pages**، تحت Source اختر **Deploy from a branch**، والفرع **main** والمجلد **/ (root)**، ثم **Save**.
7. بعد دقيقة إلى ثلاث، يظهر الرابط في أعلى نفس الصفحة بالشكل: `https://اسم-حسابك.github.io/fashion-lab/`

## التشغيل على جهازك
لا تفتح `index.html` بنقر مزدوج، فالمتصفح يمنع قراءة ملفات النموذج. شغّل `run_local.bat` (يتطلب Python) وسيفتح الموقع على `http://localhost:8000`.
